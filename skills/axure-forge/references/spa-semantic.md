# SPA 语义预处理与宿主浏览器

用于运行中的 SPA 或本地构建目录转 RP。AI 负责识别组件及定义映射；浏览器负责实际坐标、样式和当前值；引擎负责校验及 RP 写入。不要为了减噪重写整页 HTML，也不要把界面外观当成业务逻辑。

## 能力检查与宿主采集

从 `capabilities --json` 确认 web.prepare、web.capture 的 input 参数以及 web.plan/import。
版本号不能替代能力检查。先选择用户日常 Chrome/Edge 的已有标签页并核对页面与登录状态。
不要启动独立浏览器、读取配置文件或导出 Cookie；产品不再提供 web extra、storage_state 和 --browser。

先读取宿主工具文档，确认允许只读 DOM 脚本、实测坐标/样式/Range、本地 JSON 落盘及所需 PNG 截图。
缺少能力则报告具体缺口并停止完整采集；不能绕过只读限制，也不能换到无登录态的新上下文。
只读主脚本不访问存储、不发送网络请求、不驱动交互。复用登录状态不保证网站不会触发风控。

执行 `web prepare --config FILE --output NEW_DIR`，读取 manifest 的任务与 collector.js。
详细调用和本地结果字段见 [宿主采集步骤](host-capture.md)。每个任务：
页面步骤 → 保存基线 → 状态步骤 → 展开观察组件和 Tab 内容 → 恢复组件 →
probe/稳定采集 → 保存局部截图 → 恢复状态并核对原始基线 → 写入 results/<task_id>.json。
按宿主 API 做点击和输入，不能让提取脚本代替 UI 操作。已有标签页不重复导航，不重置浏览器配置。

仅截图/可访问性树的宿主不能伪造 DOM 快照；可另做明确标注估计的小范围原生重建。

## 组件识别与减噪

按页面区域检查可见组件和少量相关源码/DOM，不把整页 outerHTML 送入模型反复改写。优先读取角色、名称、当前值、可见状态、稳定标识及可观察选项。

普通按钮与普通单选优先使用原生 RP 控件。Tab、复杂弹窗、可搜索/多选/异步 Select 等保留面板或明确的简化方案。图标与按钮交互主体分开；辅助访问输入、测量容器与动画节点不应独立成为原型控件。

复杂控件先按[控件映射决策](component-mapping.md)声明稳定组件边界及已观察数据。core 负责组合树、复选框、菜单表格与日历网格；不要用业务文案和页面坐标做生成后修补。默认保真；只对用户指定组件设置 appearance:plain。

在交互配置 `pages[].components` 中声明语义根：

```json
{
  "version": 1,
  "pages": [{
    "id": "leads",
    "path": "/leads",
    "components": [{
      "kind": "select",
      "selector": "[data-forge-id='stage']",
      "value_selector": ".ant-select-content",
      "options": ["全部阶段", "待联系", "跟进中", "已邀约"]
    }]
  }]
}
```

- Select 根必须有 select/combobox 语义。value_selector 相对根匹配一个后代，读取当前显示文本；选项标签唯一且包含当前值。仅支持普通单选。
- options 是声明提供的清单。通过源码或真实展开观察取得，并在工作目录的 `semantic-review.md` 记录依据；当前引擎不能证明未挂载选项清单完整，不能补造未知选项。
- `{"kind":"button","selector":"..."}` 用于组合式按钮；普通 button 自动识别。显式按钮需要可读标签。
- `optional:true` 用于可能未挂载/隐藏的弹窗控件；它不跳过歧义选择器、错误值或不支持的控件语义。不要用 optional 掩盖正常页面缺失。
- 语义根不可嵌套。内部节点会被合并，原来绑定内部文字/箭头的事件应移到根，否则采集会明确失败。

原生 Select 自带展开/选择，不需要“打开下拉”和“选项选中”状态。去掉对应热点和状态模拟；需要业务响应时显式配置 change 事件和可验证动作。不要把所有选项绑定到同一个固定结果却声称支持真实筛选。

## 生成与验证

沿用已约定画布与目标格式：prepare → 宿主采集 → capture --input DIR → plan → import。
主采集视口取实际窗口，不强制调整窗口。逐任务核对基线、坐标、资源与状态归属；失败重采集该任务，
不能修改快照哈希绕过检查。未知选项和缺失 Tab 内容保留未知，不补造。

检查 component-report、原生控件选项/当前值/禁用状态、重复覆盖和 RP 结构。
浏览器功能、CLI 结构、Axure 视觉与交互分别记录；普通转换不自动启动 Axure 编辑器。
宿主采集的 DOM 顺序存在复杂叠层限制；集中复核 Portal 遮挡和局部图片。
不自动更新已安装 skill 或发布安装包。
